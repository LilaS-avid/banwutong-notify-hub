## 三、评测结果（这是 C 的本职）

用 **62 条样本**（其中 12 条是真实群通知）跑了两套解析器：

| 数据集 | 规则版 | 云端模型（TeleAgent） |
| --- | --- | --- |
| 合成样本 50 条 | 75.6 | **85.5** |
| **真实样本 12 条** | 46.2 | **56.7** |

**这个差距很重要**：合成样本上 85 分，真实数据上只有 56 分。真实群消息有口语、有碎片、有时间戳丢失，合成样本都没有。**所以以后验收必须用真实通知。**

详细报告在 `bangwutong-c/out/` 目录（评测报告、对比表、标注表 Excel）。

## 六、怎么复现（每步都能自己验证）

```powershell
# 1. 起后端
cd banwutong-notify-hub
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload

# 2. 起机器人（需要一个机器人的 AppID/AppSecret）
pip install -r requirements-bot.txt
python -m scripts.run_qq_bot --dry-run   # 先只打印
python -m scripts.run_qq_bot             # 再写库

# 3. 跑评测（不需要账号）
cd bangwutong-c
python src/run_parse.py --provider baseline
python src/evaluate.py --pred out/predictions_baseline.jsonl
```

## 七、三件要注意的事

1. **AppSecret / API Key 不要发群、不要截图。** 已经在聊天里泄露过一次的，去控制台重置。
2. **云端模型按 token 计费。** 50 条通知几分钱，但长期用要有人盯余额，别突然欠费停服。
3. **真实通知进测试集必须先脱敏。** 姓名、学号、手机号、群号都要换掉，这是 E 和 A 都盯的合规点。
