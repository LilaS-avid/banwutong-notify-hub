# 网页入口（手机 / 局域网访问）

> 最后更新：2026-11-02　适用：本机 Windows 部署（`.venv` + uvicorn）

## 一、三个入口

| 场景 | 地址 | 说明 |
|---|---|---|
| 本机浏览器 | <http://127.0.0.1:8765/> | 免登录（本机直连放行），功能全开 |
| 同一局域网（手机 / 别人的电脑） | <http://10.2.0.3:8765/> | 需要登录：`.env` 里的 `BANWUTONG_AUTH_USER` / `BANWUTONG_AUTH_PASSWORD` |
| 同学免登录上传 | <http://10.2.0.3:8765/?guest=1> | 访客：能看事项板、能上传文件/文字，解析走本地规则；不能编辑、不能看群消息流水 |

二维码（手机扫）：

- 主入口：`docs/qr-home.png`
- 访客上传：`docs/qr-guest-upload.png`

> 二维码里是写死的地址。换了网段、换了机器，用
> `python -m scripts.make_qr --url "http://新IP:8765/?guest=1" --out docs/qr-guest-upload.png`
> 重新生成。

## 二、怎么改监听范围

`start-all.ps1` 默认 `-BindAddress 0.0.0.0`（对局域网开放），启动完会直接打印可用地址。

```powershell
.\start-all.ps1                        # 局域网可访问（默认）
.\start-all.ps1 -BindAddress 127.0.0.1 # 只允许本机
.\start-all.ps1 -Port 9000             # 换端口
```

桌面上的「启动班务通」走的是 `scripts/launcher.ps1`，也已经改成 `0.0.0.0`。

## 三、手机打不开时按顺序查

1. **是不是同一个网段**：手机 Wi-Fi 的 IP 要和 `10.2.0.x` 同网段。
   电脑 IP 用 `Get-NetIPAddress -AddressFamily IPv4` 看，变了就重新生成二维码。
2. **端口是否在听**：`Get-NetTCPConnection -State Listen -LocalPort 8765`，
   应当看到 `0.0.0.0`，不是 `127.0.0.1`。
3. **防火墙**：这台机器三个配置文件都是关闭状态，一般不用管；
   如果以后开了防火墙，需要放行 TCP 8765。
4. **登录打不开**：确认 `.env` 的账号密码；改完 `.env` 要重启后端
   （`stop-all.ps1` → `start-all.ps1`）。

## 四、要给外网用怎么办

现在是 `10.2.0.3`（私网），公网访问不了。两条路：

| 方案 | 前提 | 安全性 |
|---|---|---|
| 路由器端口映射 8765 → 10.2.0.3:8765 | 路由器管理权限、有公网 IP | **不建议**：HTTP 明文，密码会被抓 |
| 内网穿透（Cloudflare Tunnel / frp 等） | 装一个客户端，不用改路由器 | 穿透服务自带 HTTPS，相对稳妥 |

不管哪种，先做三件事：

1. 把 `BANWUTONG_AUTH_PASSWORD` 换成强密码（现在是 15 位，够长就保持）；
2. 确认「访客上传」链接只发给本班同学——访客能看到整块事项板；
3. 云模型额度是按调用计费的，公网暴露后建议把主页模型切到「本地规则」，需要时再切回来。

## 五、和 QQ 机器人的关系

机器人走 `http://127.0.0.1:8765`，属于本机直连，**不受登录影响**；
网页对外开放不会改变机器人的行为，也不会多开一个后端进程。
