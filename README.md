# 班务通

班级通知理解与报名提醒助手。

班务通通过 QQ 或企业微信机器人接收班级通知，自动提取报名条件、截止时间、材料和链接，合并重复与变更通知，并在电脑和手机端生成统一提醒与可报名项目索引。

## 项目状态

当前处于需求确认和 MVP 设计阶段，暂未开始业务代码开发。

## MVP 目标

第一版只完成一条真实闭环：

```text
班级群通知
→ 机器人接收
→ AI 提取结构化信息
→ 去重与更新合并
→ 电脑/手机网页展示
→ 截止前提醒
```

MVP 不包含自动提交报名、应用商店上架、多学校复杂权限和大规模并发。

## 核心原则

- 先接入一个稳定来源和一个班级，跑通完整链路后再扩展。
- AI 可以生成代码，团队成员负责平台授权、验收和最终决策。
- 每条提醒必须保留原始通知和来源，不能只保存 AI 总结。
- 无法确定的信息允许进入系统，但必须明确标记为待核对。
- 不绕过平台登录、验证码和访问控制。

```text
apps/
  api/          # 后端 API
  web/          # 响应式 PWA
services/
  worker/       # 定时任务、OCR、项目索引
adapters/
  qq/           # QQ 机器人适配器
  wechat/       # 企业微信等平台适配器
docs/           # 项目文档
infra/          # Docker 与部署配置
tests/          # 自动化测试和通知样例
```

## 团队协作

- 五名成员共同使用本仓库和一个 AI 主控会话。
- 每次只实现一个可演示、可验收的功能。
- 通过验收后再提交；数据库结构、API 字段和消息格式变更必须同步更新文档。
- 密钥、机器人 Token、真实学生信息和生产数据不得提交到仓库。

## 下一步
